# CaloriesControl：iPhone 日常使用

配合 [技术方案.md](./技术方案.md) v0.2。给**自己的 iPhone + Apple Watch** 用：不上架、不申请开发者账号。

---

## 你主屏幕上会有什么

| 图标 | 谁提供 | 干什么 |
|---|---|---|
| **热量控制** | 本项目网页 → Safari「添加到主屏幕」 | 每天主要入口：看建议、拍照记账 |
| **快捷指令** | 苹果系统 | 装一条「热量控制-同步今日消耗」，平时可不必点开这个 App |
| **健身** | 苹果系统 | 看活动环；和手表是同一套运动数据 |
| **健康** | 苹果系统 | 一般不用打开 |
| 手表上的 **健身** | 苹果系统 | **运动中**在这里开始跑步、步行、力量训练 |

不会出现一个从 App Store 下载的「CaloriesControl」；也没有自己的表盘数字。

## 第一次设置（只做一次）

1. 用 **Safari** 打开 **https://carrieliangjzh.github.io/CaloriesControl/**（不要用微信）。
2. 分享 → **添加到主屏幕**，名字用「热量控制」。
3. 打开主屏幕图标，在「我的」里填写：年龄、性别、身高、体重、目标、目标类型。
4. 如需拍照识别或建议润色：在「我的」粘贴自己的 Gemini API Key（只存在这台手机浏览器里）。无 Key 仍可手填饮食，建议用规则短句。
5. 安装快捷指令「热量控制-同步今日消耗」：打开网页「今日」底部说明，或进入 `#/sync`。名称必须一字不差。
6. 第一次运行指令时，允许读取**活动能量**。
7. 手表保持与 iPhone 配对，运动仍用系统健身，不必改手表设置。

## 每天怎么点

### 早上或第一餐前

1. 点主屏幕 **热量控制**（应是独立窗口，不要从 Safari 书签进）。
2. 点 **同步手表**（会跳到快捷指令再跳回来）。若没跳回，到首页 **手填今日消耗**（看一眼健身 App 的活动环千卡即可）。关掉指令权限时，手填同样能出建议。
3. 看：目标、已吃、手表已消耗，以及饮食指令（不吃 / 减量 / 加量）和训练指令（练 / 休 / 只走路）。

### 每吃一顿

1. 点底栏 **饮食**。
2. 点 **拍照** 或 **相册**（没有 Gemini Key 时用手填）。
3. 核对菜名、克数、餐次，不对就改，再保存。改克数时热量按比例缩放。
4. 回到 **今日**：高热量会出减量/不吃；蛋白不够会出加量。

### 去运动

1. 先看「训练」里今天的清单。若手表已经记到跑步 ≥30 分钟，同类有氧会标成「手表已记，不叠加」。
2. 抬腕，用手表 **健身** 开始相应运动（和平时一样）。
3. **不要**指望网页里「开始跑步」。网页不负责 GPS 和心率。

### 练完或晚上

1. 再打开热量控制，再点一次 **同步手表**。
2. 若今天已经跑过或力量练过，训练建议应是恢复 / 只走路，而不是再推一节同类有氧。连续三天高强度会提示休息。

## 你不必做的事

- 不用每周连电脑重装 App
- 不用上架、不用开发者账号
- 不用每天打开「健康」抄数字（同步失败时才看健身圆环手填）
- 电脑只在改网页、部署时需要；日常吃饭训练不用电脑

---

## 和商店 App 的差别（会感觉到）

- 图标是「加到主屏幕的网页」，不是商店应用；可能仍有一点网页感
- 同步消耗时，系统会问快捷指令是否读取健康数据
- 手表表盘上**没有**本产品的剩余热量；要看数字请打开主屏幕「热量控制」或系统健身
- 清掉 Safari / 该网站数据会丢失本机日记，清理前先导出（导出为 P4）

## 出问题先看这里

| 现象 | 处理 |
|---|---|
| 点同步手表后停在快捷指令、不跳回 | 最后一步必须是「打开 URL」。先把 kcal 设为 0，读失败也打开网页。站点更新后，指令报错也会自动跳回并提示手填 |
| 手表没电 / 没读到消耗 | 应跳回网页；对照健身 App 活动环手填。手填后今日仍会出建议 |
| 预览提示「尝试共享 N 个健康项目」 | 「打开 URL」误带了健康样本。先对样本做「计算统计数据 → 总和」，再「设置变量」成数字后才拼进网址。不要把查找结果的「总和」直接拖进打开 URL。仍拦时：设置 → 快捷指令 → 高级 → 允许共享大量数据 |
| 回跳提示缺少日期 | 快捷指令「打开 URL」会截掉 `&` 后面的参数。把文本改成 `网站#/sync/2026-09-18/387` 这种路径，不要用 `?activeKcal=&date=` |
| 拍照没反应 | 用 Safari 或主屏幕图标打开（不要用微信内置浏览器）；检查 Key。无 Key 改手填 |
| 建议只有热量没有「减量」文案 | 先确认是否已保存饮食；无 Key 时只有规则短句，不会润色 |
| 打开是 Safari 而不是独立窗口 | 必须用「添加到主屏幕」的图标，不要从书签列表进 |
| 微信里打开 | 右上角 ··· → 在 Safari 打开 |
| 训练清单仍推跑步 | 先同步手表；有 ≥30 分钟有氧后，网页会去掉同等有氧 |
