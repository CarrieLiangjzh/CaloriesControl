# 实现说明

与 [技术方案.md](./技术方案.md) v0.2 对齐。栈在 M0 选定。

## 技术选型

| 项 | 选择 | 原因 |
|---|---|---|
| 打包 | Vite 8 + TypeScript | 技术方案默认；Windows 可开发 |
| UI 库 | **不用 React** | Tab 与表单用原生 DOM 足够；少依赖 |
| 路由 | `location.hash` | 合同为 `/#/sync?...`，静态托管无需服务器 rewrite |
| 样式 | 单文件 `src/styles.css` | 无 CSS 框架 |
| 存储 | 资料、健康日、饮食日、建议快照、周训练勾选、Gemini Key 均用 `localStorage`；识别草稿用 `sessionStorage` | 体量小；IndexedDB 留待导出 |
| 测试 | Vitest | GoalMath、ShortcutSync、饮食、AdviceEngine、周模板 |

## 目录

```
web/
  src/
    main.ts
    shell.ts
    router.ts
    styles.css
    env/display.ts        # 微信 / 主屏幕独立窗口
    features/
    domain/               # GoalMath、AdviceEngine、WorkoutPlan、food
    data/
    gemini/               # 压缩图、识别、建议润色
```
