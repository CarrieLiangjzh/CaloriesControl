# 数据层

- 个人资料：`localStorage` `calories-control:profile:v1`
- 健康日缓存：`localStorage` `calories-control:health-days:v1`（约 21 天）
- 饮食日记：`localStorage` `calories-control:food-days:v1`（约 21 天）
- 识别草稿：`sessionStorage` `calories-control:food-draft:v1`
- Gemini Key：`localStorage` `calories-control:gemini-key:v1`
- 建议快照：`localStorage` `calories-control:advice-snapshot:v1`（饮食或消耗变化后按指纹失效）
- 周训练勾选：`localStorage` `calories-control:workout-week:v1`（换周或换目标会重开）
