# 快捷指令：热量控制-同步今日消耗

名称必须一字不差：**热量控制-同步今日消耗**。网页点「同步手表」会运行这条指令并把输出带回网站。

不要用「打开 URL」：从 Safari / 主屏幕网页唤起时，系统经常拦住跳转。最后一步用 **停止并输出** 一个数字即可。

## 在 iPhone 上创建

1. 打开「快捷指令」→ **+**。
2. 标题改为 `热量控制-同步今日消耗`。
3. **设置变量** `kcal` = `0`。
4. **查找健康样本**：活动能量，开始日期为今天。允许健康权限。不要打开「限制」。
5. **如果**样本有任何值：对样本 **计算统计数据** 求总和，再把 `kcal` 设成该总和。
6. 「如果」外面添加 **文本**，内容只有 `kcal` 变量。
7. **替换文本**：把 `,` 换成 `.`。
8. **停止并输出**：输出替换后的文本。

在指令里点播放，应得到 `153.381` 这种数字。再从热量控制点「同步手表」才会写回今日。
