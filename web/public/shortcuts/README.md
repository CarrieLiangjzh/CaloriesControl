# 快捷指令：热量控制-同步今日消耗

名称必须一字不差：**热量控制-同步今日消耗**。网页点「同步手表」会运行这条指令，并把当前网站地址作为输入（本机预览例如 `http://192.168.x.x:5173/`）。

指令要做的事：读健康里**今天的活动能量总和（千卡）**，再打开：

```
{输入}#/sync?activeKcal={总和}&date={yyyy-MM-dd}
```

`workouts` 可选。日期必须是**今天**，否则网页拒绝写入。

## 在 iPhone 上创建

1. 打开「快捷指令」→ **+**。
2. 标题改为 `热量控制-同步今日消耗`。
3. **接收快捷指令的输入** → 文本。
4. **获取当前日期** → **格式化日期** → 自定义 `yyyy-MM-dd`。
5. **查找健康样本**：活动能量，开始/结束均为今天。允许健康权限。
6. **统计**：对样本求和。若系统用千焦，再除以 4.184。
7. **文本**：`[快捷指令输入]#/sync?activeKcal=[总和]&date=[格式化日期]`（方括号处插入变量）。
8. **打开 URL**：使用上一步文本。

详细步骤也写在网页「今日」底部和 `#/sync`。失败时在「今日」手填健身活动环千卡。
