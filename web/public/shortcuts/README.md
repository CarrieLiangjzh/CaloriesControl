# 快捷指令：热量控制-同步今日消耗

名称必须一字不差：**热量控制-同步今日消耗**。网页点「同步手表」会运行这条指令。新版 iOS 搜不到「接收」，不必加；网址写死即可。

指令要做的事：读健康里**今天的活动能量总和（千卡）**，再打开（不要用 `?` 和 `&`）：

```
https://carrieliangjzh.github.io/CaloriesControl/#/sync/{yyyy-MM-dd}/{kcal}
```

先把 `kcal` 设为 `0`。找不到样本或手表没电时保持 0，**最后一步仍打开 URL**，这样会跳回网页。日期必须是今天。

## 在 iPhone 上创建

1. 打开「快捷指令」→ **+**。
2. 标题改为 `热量控制-同步今日消耗`。
3. **获取当前日期** → **格式化日期** → 自定义 `yyyy-MM-dd`。
4. **设置变量** `kcal` = `0`。
5. **查找健康样本**：活动能量，开始日期为今天。允许健康权限。不要打开「限制」。
6. **如果**样本有任何值：对样本 **计算统计数据** 求总和，再把 `kcal` 设成该总和。不要把查找结果自带的「总和」拖进打开 URL。
7. 在「如果」外面添加 **文本**：`https://carrieliangjzh.github.io/CaloriesControl/#/sync/[格式化日期]/[kcal]`。
8. **打开 URL**：使用上一步文本。必须是最后一步。

详细步骤也写在网页「今日」底部和 `#/sync`。指令报错时网页会自行跳回并请你手填。
